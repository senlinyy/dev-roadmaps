title: "Inspect Database and Recovery Evidence"
sectionSlug: backups-and-high-availability
order: 2
---

Inspect Cloud SQL instance `orders-postgres-prod` and its backup evidence. Verify engine version, regional placement, high-availability mode, private connectivity, public exposure, backup status, and point-in-time recovery.

The production requirement is a private PostgreSQL instance with regional availability and recoverable transaction history.
