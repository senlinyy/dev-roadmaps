The security team owns a bounded block inside `sshd_config`. Manage the complete block with stable markers, validate the candidate with `sshd -t`, and enable diff output for review.

Work across the provided files as needed. The grader checks the resulting Ansible project, including relationships between files, rather than matching a sample answer.
