Connect a production Vault file to the deployment play and consume its token without placing plaintext in the playbook. The encrypted file must remain a Vault payload and the secret-using task must suppress sensitive output.

Work across the provided files as needed. The grader checks the resulting Ansible project, including relationships between files, rather than matching a sample answer.
